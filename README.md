# AZ-104 Operational Labs

This repository contains hands-on Microsoft Azure administration labs aligned with the AZ-104 Microsoft Azure Administrator certification.

The purpose of these labs is to develop practical understanding of Azure administration by performing real configuration tasks in the Azure Portal.

---

## Purpose

This project documents practical experience in:

- Microsoft Entra ID identity and access management
- Role-Based Access Control (RBAC)
- Resource group administration
- Azure subscription structure and governance
- Core infrastructure services in Azure

Each lab focuses on applied learning through real Azure configurations rather than theoretical study.

---

## Lab Structure

Each lab is organised into its own folder.

01-iam-rbac  
02-resource-groups  
03-storage-accounts  
04-virtual-machines  
05-networking-basics  

Each folder contains:

- A README file describing the lab
- Steps taken during implementation
- Key concepts learned
- Optional screenshots for validation

---

## Core Skills Covered

Identity and Access Management
- Microsoft Entra ID users and groups
- Security group creation and management
- Role-Based Access Control (RBAC)
- Scope-based permissions at subscription and resource group level

Azure Administration
- Resource group creation and management
- Azure Portal navigation and configuration
- Subscription-level structure understanding

Infrastructure Fundamentals
- Storage account configuration (planned)
- Virtual machine deployment (planned)
- Basic networking concepts (planned)

---

## Security and Best Practice Approach

These labs follow Azure best practices where applicable:

- Least privilege access model
- Group-based RBAC assignment instead of direct user permissions
- Scope-aware permission management
- Separation of identity and resource configuration responsibilities

- Identity provider: Microsoft Entra ID default directory
